# Supported Icon Keys

These are the icon keys supported by the current Symfonium external icon-pack contract.

Both sample packs map every key below (361 keys). The filled pack uses `@drawable/ic_filled_*`; the outline pack uses `@drawable/ic_outline_*`. You can delete mappings you do not want to override; Symfonium falls back to its built-in icon for missing keys.

Keys ending in `.selected` are selected tab or selected navigation state variants. Keep them separate from the unselected key when your icon style has distinct selected and unselected artwork.
